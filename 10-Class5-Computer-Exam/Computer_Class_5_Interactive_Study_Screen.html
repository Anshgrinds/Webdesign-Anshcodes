⚙ Ch 1: Computer Fundamental IPO Cycle

A computer is an electronic machine that processes raw Data into meaningful Information using the IPO (Input-Process-Output) cycle.

  • Speed: Operates in microseconds and nanoseconds.
  • Accuracy & GIGO: 100% accurate (Garbage In, Garbage Out).
  • Diligence: Never tires or gets distracted.
  • Limitations: Zero IQ, no independent thinking, no feelings.
💻 Ch 2: Computer System Components

A complete computer system consists of five essential pillars:

  • Hardware: Physical tangible parts (Keyboard, CPU box, Monitor).
  • Software: Electronic programs giving instructions (OS, Paint).
  • Data: Raw unorganized input facts and numbers.
  • Liveware (Humanware): Users and programmers operating it.
  • Procedures: Rules and operational instructions.
🖥 Ch 3: Hardware & Memory Architecture
  • CPU: ALU (Arithmetic/Logic) + CU (Control Traffic) + MU (Registers).
  • Printers: Impact (Dot Matrix — noisy) vs Non-Impact (Inkjet — liquid spray; Laser — dry toner & laser).
  • Plotter: Large architectural maps and giant banners.
  • RAM vs ROM: RAM is volatile (lost on power off); ROM is permanent (holds boot BIOS).
💾 Ch 4: Software Types OS & Apps
  • System Software: Controls hardware. Includes Operating System (Windows 11, macOS, Linux, Android) and Utilities (Antivirus, Disk Defrag).
  • Application Software: Performs user tasks. Includes General Purpose (MS Word, MS Excel, Paint) and Customized (School fee software, Hospital billing).
🌎 Ch 5: Digital Computer Types Classification
  • Supercomputer: Fastest, costliest. NASA, weather forecasting (Frontier, Fugaku).
  • Mainframe: Massive multi-user servers for banks, airline bookings.
  • Minicomputer: Midrange servers for university labs.
  • Microcomputer (PC): Desktop, Laptop, Tablet, Smartphone.
🌐 Ch 6: Internet & Services Network of Networks
  • WWW: World Wide Web (Invented 1989 by Tim Berners-Lee).
  • URL: Uniform Resource Locator (Unique web address).
  • Browser vs Search Engine: Browser is app (Brave, Chrome); Search Engine is site (Google, Bing).
  • Cyber Safety: Never share real passwords, home address, or phone numbers online.
🎬 Ch 7: Multimedia 5 Elements

Derived from Multi (many) + Media (medium of communication).

  • 5 Elements: 1. Text • 2. Audio • 3. Graphics • 4. Video • 5. Animation.
  • Animation: Rapid sequence of drawings creating the illusion of movement.
  • Uses: Smart classes, 3D video games, animated movies, medical surgery models.
🎨 Ch 8: Fun with Paint Tools & Tricks
  • Shift Key Trick: Hold Shift to draw perfect circles and squares.
  • Eraser Resize: Ctrl + + enlarges eraser, Ctrl + - shrinks it.
  • Color Leak Fix: If color spills over, press Ctrl + Z (Undo) and close gaps.
  • Transparent Selection: Keeps background transparent when moving objects.
