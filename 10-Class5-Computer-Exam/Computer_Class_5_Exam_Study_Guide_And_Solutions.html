PART 1: CHAPTER-BY-CHAPTER REVISION MASTERCLASS SYLLABUS CORE
Chapter 1: Computer Fundamental IPO Cycle & Characteristics
  • Definition: A computer is an electronic device that accepts raw Data as input, processes it according to stored instructions, and produces meaningful Information as output.
  • IPO Cycle: Input (Data entered via keyboard/mouse) → Process (CPU performs arithmetic/logic) → Output (Result displayed on monitor or printed on paper).
  • Key Characteristics:
    • Speed: Performs millions of calculations in fractions of a second (nanoseconds/microseconds).
    • Accuracy: Gives 100% accurate results. Errors occur only if wrong input is provided (GIGO = Garbage In, Garbage Out).
    • Diligence: Never gets tired, bored, or loses concentration even after continuous hours of work.
    • Versatility: Can perform diverse tasks (typing essays, playing games, playing music, drawing).
    • Storage: Can store huge volumes of data permanently in secondary storage.
    • Limitations: Zero IQ (No Intelligence Quotient), cannot think on its own, and has no human feelings or emotions.
Chapter 2: Computer System Hardware, Software & Liveware
  • Definition: A computer system is an integrated set of functional components working harmoniously to process data into information.
  • Five Essential Components of a Computer System:
    1. Hardware: Tangible physical components you can see and touch (Keyboard, CPU box, Monitor, Mouse).
    2. Software: Intangible set of programs and instructions that tell the hardware what to do (Windows, MS Paint).
    3. Data: Raw, unorganized facts, letters, symbols, or numbers fed into the computer.
    4. Liveware (Humanware): The people who operate, program, or manage the computer system (Users, Programmers).
    5. Procedures: Step-by-step rules and guidelines governing the usage and operations of the computer system.
Chapter 3: Computer Hardware Input, Processing (CPU), Output & Memory
  • Input Devices: Keyboard (104+ keys, Function F1-F12), Optical Mouse (Left/Right click, Scroll), Scanner (flatbed, converts hardcopy to digital image), Microphone (audio voice input), Web Camera (live video input), Barcode Reader, Light Pen.
  • Central Processing Unit (CPU) — "Brain of the Computer":
    • ALU (Arithmetic Logic Unit): Carries out arithmetic operations (+, -, ×, ÷) and logical decisions (<, >, =).
    • CU (Control Unit): Acts as the "Traffic Police" of the system; directs and coordinates all hardware activities.
    • MU (Memory Unit / Registers): Holds data and instructions currently being processed by the CPU.
  • Output Devices:
    • Monitor (VDU): Displays soft copy. Types: CRT (bulky vacuum tubes), LCD (flat, energy-saving), LED (sharper, modern).
    • Printer: Produces permanent hard copy on paper.
      • Impact Printers: Strike ribbon physically against paper (e.g., Dot Matrix Printer — noisy, low cost).
      • Non-Impact Printers: No physical strike. Inkjet Printer (sprays liquid ink droplets) and Laser Printer (uses laser beam & dry toner powder; fastest and crispest).
    • Plotter: Prints high-precision, large-format engineering blueprints, architectural maps, and giant banners.
    • Speakers & Headphones: Audio/sound output.
  • Computer Memory Architecture:
    • Primary Memory (Main Memory): Directly accessible by CPU.
      • RAM (Random Access Memory): Read and Write, Volatile (erased when electricity turns off).
      • ROM (Read Only Memory): Permanent, Non-Volatile, contains startup booting instructions (BIOS).
    • Secondary Storage: Permanent external storage. Hard Disk Drive (HDD), Solid State Drive (SSD), USB Pen Drive, Compact Disc (CD: 700 MB), Digital Versatile Disc (DVD: 4.7 GB), Blu-ray (25–50 GB), Memory Card.
Chapter 4: Computer Software System Software vs. Application Software
  • System Software: Controls the internal operations of computer hardware.
    • Operating System (OS): The master software that acts as a bridge/interface between the user and hardware (Windows 11, macOS, Linux, Android). Manages memory, processor, files, and connected devices.
    • Device Drivers: Special programs that allow the OS to communicate with specific hardware (printer drivers, sound drivers).
    • Utility Software: Maintenance and health tools: Antivirus (Windows Defender, Quick Heal, Norton), Disk Cleanup, Disk Defragmenter, Compression tools (WinRAR).
  • Application Software: Designed to perform specific user-requested tasks.
    • General-Purpose Software: Packaged software used by the public: Word Processors (MS Word), Spreadsheets (MS Excel), Graphics (MS Paint, Photoshop), Presentation (MS PowerPoint).
    • Customized / Specific-Purpose Software: Specially built for specific organizations: School billing software, Hospital patient management, Airline ticket reservation systems.
Chapter 5: Types of Digital Computers Classification by Size, Speed & Capacity
  • 1. Supercomputer: The largest, fastest, and most expensive computers on Earth. Can execute billions of calculations per second. Used for weather forecasting, space exploration (NASA/ISRO), satellite tracking, and atomic simulations. Examples: Frontier, Fugaku, PARAM Shivay.
  • 2. Mainframe Computer: Very large and powerful multi-user computers. Can support thousands of users simultaneously. Used by commercial banks, airline booking centers, and government census departments. Example: IBM Z-Series.
  • 3. Minicomputer: Mid-sized multi-user computer, more powerful than a PC but smaller than a mainframe. Used in university laboratories and manufacturing factories. Examples: PDP-11, VAX.
  • 4. Microcomputer (Personal Computer / PC): The most widely used single-user computer powered by a single microprocessor chip. Types:
    • Desktop Computer: Placed on a desk; has separate monitor, CPU box, keyboard, and mouse.
    • Laptop (Notebook): Lightweight, portable computer with integrated screen, keyboard, touchpad, and rechargeable battery.
    • Tablet PC: Slate-like device operated by finger touch or digital stylus.
    • Smartphone: Handheld pocket device combining cellular telephone with high-speed internet and computing apps.
Chapter 6: The Internet and its Services Networking, Terminology & Cyber Safety
  • Definition of Internet: The global network of millions of interconnected computers across the world ("Network of Networks").
  • Essential Terminology:
    • WWW (World Wide Web): A vast collection of linked multimedia documents and pages on the internet. Invented by Tim Berners-Lee in 1989.
    • Web Page: A digital electronic page written in HTML containing text, pictures, videos, and links.
    • Website: A collection of related web pages under a shared address (e.g., www.google.com).
    • Home Page: The introductory or main first page of any website.
    • URL (Uniform Resource Locator): The unique web address of a specific page or site.
    • Web Browser: Software program used to open and navigate web pages (Brave, Chrome, Edge, Firefox, Safari).
    • Search Engine: A website tool used to search information using keywords (Google, Bing, Yahoo).
    • ISP (Internet Service Provider): Company providing internet connections (WorldLink, Nepal Telecom, Subisu).
  • Major Services: E-mail (Electronic Mail: To, Cc, Bcc, Subject, Attachment), E-Commerce (Online shopping: Daraz, Amazon), E-Banking (eSewa, Khalti), Video Calling (Zoom, Google Meet), Cloud Storage (Google Drive).
  • Netiquette & Cyber Safety for Grade 5: Never share real passwords, home address, or phone number with strangers online; be polite in chat; inform parents/teachers if someone makes you uncomfortable online.
Chapter 7: Multimedia Elements, Applications & Hardware
  • Definition: Formed from Multi (many) and Media (medium of communication). Multimedia is the computer-controlled combination of multiple media elements into a unified interactive presentation.
  • Five Essential Elements of Multimedia:
    1. Text: Words, numbers, headings, and character descriptions.
    2. Audio (Sound): Music, speech, narration, and audio sound effects.
    3. Graphics (Images): Photographs, diagrams, drawings, and charts (JPEG, PNG).
    4. Video: Continuous photographic frames recorded in real life with audio (MP4).
    5. Animation: Illusion of movement created by playing a rapid sequence of drawn still pictures.
  • Key Applications:
    • Education: Smart classes, interactive animated science CD-ROMs, virtual encyclopedias.
    • Entertainment: 3D cartoon movies (Disney/Pixar), video games, music streaming.
    • Advertising: TV commercials, interactive digital product banners.
    • Medicine: 3D surgery simulations and human anatomy modeling for training doctors.
  • Multimedia Hardware: Fast CPU, Color Monitor, Graphics Card, Sound Card, Speakers/Headphones, Microphone, Web Camera.
Chapter 8: Fun with Paint (MS Paint) Tools, Brushes, Selection & Transformations
  • Introduction: A drawing and painting program included in Microsoft Windows.
  • Main Window Components: Title Bar, Quick Access Toolbar, Ribbon (Home and View Tabs), Canvas (Drawing Area), Color Palette (Color 1 = Foreground, Color 2 = Background), Status Bar.
  • Key Tools:
    • Pencil: Freehand thin line drawing.
    • Fill with Color (Paint Bucket): Fills an enclosed shape with Color 1. (Note: If the shape has any tiny gap or leak, the color spills over the whole canvas!).
    • Text Tool (A): Adds typed words with font styles.
    • Eraser: Cleans drawing area with Color 2. (Shortcut: Ctrl + + enlarges eraser, Ctrl + - shrinks eraser).
    • Color Picker (Eyedropper): Samples and selects an exact color from any part of the canvas.
    • Magnifier: Zooms in on a specific area to inspect fine details.
  • Shapes & Modifiers: Holding the Shift key while drawing forces shapes to form perfect squares, circles, or straight horizontal/vertical lines. Curve tool bends a line twice.
  • Selection Tools:
    • Rectangular Selection: Selects a neat box/rectangle.
    • Free-form Selection: Selects an irregular, hand-drawn outline.
    • Transparent Selection: Makes the white background transparent so underlying artwork remains visible.
  • Image Transformations: Rotate (90°, 180°), Flip Horizontal (mirror reflection left-right), Flip Vertical (upside-down), Resize & Skew, Crop.

Q6. Short Answers & Marking Key [5 × 2 = 10 Marks]

(a) What is a Computer? Name the three steps of the IPO cycle.
Answer: A computer is an electronic data processing machine that accepts raw data, processes it according to instructions, and generates meaningful information. The three steps of the IPO cycle are: Input, Process, and Output. [1 Mark Definition + 1 Mark Steps]

(b) What is an Operating System? Give two common examples.
Answer: An Operating System (OS) is the master system software that acts as an interface between the user and computer hardware, managing all hardware and software resources. Examples: Microsoft Windows 11 and Google Android (or macOS/Linux). [1 Mark Definition + 1 Mark Examples]

(c) Mention any four major types of Digital Computers based on size and power.
Answer: The four major types of digital computers are: 1. Supercomputer, 2. Mainframe Computer, 3. Minicomputer, and 4. Microcomputer (PC). [0.5 Mark each = 2 Marks]

(d) Name the five core elements that make up Multimedia.
Answer: The five core elements of multimedia are: 1. Text, 2. Audio (Sound), 3. Graphics (Images), 4. Video, and 5. Animation. [2 Marks for all 5 correct]

(e) In MS Paint, how does Free-form Selection differ from Rectangular Selection?
Answer: Rectangular Selection selects an area in a straight, box-shaped rectangular boundary, whereas Free-form Selection allows the user to draw an irregular, custom curved outline around any specific object to select it. [1 Mark each definition = 2 Marks]

Basis Web Browser Search Engine

Q8. Application & Practical Problem Solutions [2 × 2 = 4 Marks]

(a) Aarav's Paint Spillage Problem:
Reason: Aarav's roof drawing was not a completely closed shape; it had a tiny opening or leak, causing the color to spill out over the entire canvas.
Fix: Aarav should immediately press Undo (Ctrl + Z) to reverse the spill, zoom in using the Magnifier tool, close the gap using the Pencil or Line tool, and then re-apply the Fill with Color tool. [1 Mark Reason + 1 Mark Fix]

(b) Prakriti's Internet Service & Safety:
Service: She should use Electronic Mail (E-mail) with an attachment (or cloud sharing).
Two Safety Rules: 1. Never share sensitive personal details or passwords with unknown persons. 2. Never open email attachments or click links sent by strangers. [1 Mark Service + 1 Mark Safety]
